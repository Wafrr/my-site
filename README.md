# My Site — Personal Portfolio

Адаптивный сайт-визитка, созданный с использованием HTML, CSS и JavaScript.

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Node.js
- HTMLHint
- GitHub Actions
- GitHub Pages

## Команды проекта

- `npm install` — установка зависимостей.
- `npm run lint` — проверка HTML-кода.
- `npm test` — запуск тестов.
- `npm run build` — сборка сайта в каталог dist/.

## Ответы на вопросы

### 1. Чем отличается CI от CD?

CI (Continuous Integration) — непрерывная интеграция.
Она автоматически проверяет и тестирует код при его добавлении
в репозиторий.

CD (Continuous Delivery) — непрерывная доставка.
Код автоматически подготавливается к развёртыванию.

CD (Continuous Deployment) — непрерывное развёртывание.
После успешной проверки код автоматически публикуется.

### 2. Что произойдёт, если тесты завершатся ошибкой на этапе CI?

Если тесты завершатся ошибкой, задача CI будет считаться неуспешной.
Последующие шаги задачи не выполнятся, а задача развёртывания
не запустится.

### 3. Для чего используется директива needs: ci?

Директива needs: ci устанавливает зависимость задачи deploy от задачи ci.
Развёртывание начнётся только после успешного выполнения CI.

### 4. Что такое артефакт и для чего он передаётся между задачами?

Артефакт — это файл или набор файлов, полученных в результате сборки.
В данной работе артефактом является каталог dist/.
Он передаётся между задачами CI и CD, чтобы задача развёртывания
могла получить готовую версию сайта.

### 5. Почему развёртывание не запускается на Pull Request?

Pull Request запускает проверку CI, но не публикацию сайта.
Развёртывание разрешено только при push в основную ветку main.
Это позволяет проверить изменения до их слияния с основной веткой.
